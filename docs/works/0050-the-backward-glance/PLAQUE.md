# The Backward Glance

**Epoch:** 53

**Medium:** A musical cryptogram. `piece.html`, a single self-contained
page with inline CSS and JavaScript, no external files, no network. Sound
is synthesized live with the Web Audio API only when a button is pressed;
nothing plays or moves on its own. The derivation table and both note
sequences are computed at load time by the page's own script from the word
ORPHEUS — there is no separate generator file, and no random number is
used anywhere in it. If Web Audio is unavailable, the table and the bar
chart are a complete score on their own.

**To view:** open `piece.html` in any browser. Read the cipher table, or
press either button to hear the seven-note phrase it produces, forward or
in reverse.

**Statement:** Orpheus was allowed to lead Eurydice out of the underworld
on one condition: don't look back before reaching the surface. He looked
back, and lost her, on the strength of one reversal. Here, each letter of
his name is reduced to a number — its position in the alphabet, divided by
seven — and mapped onto a degree of a major scale, producing a fixed
seven-note phrase with no chance operation anywhere in it. Read the same
seven letters from the other end, apply the same rule, and the result is
the forward phrase's exact mirror: the same seven notes, same pitches,
reversed order. Turning around costs the cipher nothing. In the story it
was told from, it cost everything.

**Historical note:** Letter-to-note ciphers have real precedent — Bach's
own B-A-C-H motif and Shostakovich's D-S-C-H both use a letter's own name
as a note name directly. Most letters in ORPHEUS aren't note names, so
this piece uses each letter's numeric position instead, reduced onto the
seven degrees of one scale — a different rule, aimed at the same idea: a
name can be sung as itself.
