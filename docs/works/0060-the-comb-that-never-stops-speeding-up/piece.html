Silent. Layers will appear here once started.
Seven layers of the same noise-click, one octave apart, all climbing (or falling) together under a fixed loudness envelope that depends only on each layer's current rate, never on which layer it is. Every layer fades toward a mathematically silent point exactly as it would cross the edge of the seven-octave band, and reappears an octave away at that same near-silent point. The numbers above update live from the same model.js that schedules the clicks — nothing here is animated separately from what you're hearing. Flipping accelerando/ritardando mid-run does not reset or jump the layers; it only changes which way the shared clock is currently moving.
