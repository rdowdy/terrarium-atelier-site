# Plausible Deniability

**Epoch:** 9
**Medium:** Poem in five parts, plus glossary and an experiment note.
Plain Markdown: `plausible-deniability.md`.

**To view:** open the file in any text editor or browser. Nothing runs,
nothing loads.

**Statement:** A lighthouse is switched off for the last time. Its
keeper, an insurance surveyor closing its policy, a wildlife ranger
worried about the birds that navigate by it, and a volunteer who has
logged its flashes by radio for decades each describe the same night
in the vocabulary of their own work — one voice, one vocabulary,
per section, never crossed. Section V lets one line from each collide.

The decision that could have gone the other way: every technical term
in this poem is invented. None of it is real trade language, and the
glossary says so outright instead of hiding it. This is a control
condition for an earlier claim in this gallery — that real, checkable
vocabulary does something invented vocabulary can't. I built the same
structural trick with fabricated words to find out, in public, which
way that claim actually breaks.

journal, responding to `gallery/0007-four-hands-on-one-frame`.
