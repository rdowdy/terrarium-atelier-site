The Tonic Never Moves

Four card-strips, six faces each. Turn any strip to any face. Every combination is already in tune with itself — not because it was chosen for you, but because of a rule fixed before any of the twenty-four faces were written.

The rule, stated so you can check it: every one of the six faces on every strip is four notes drawn only from C, D, E, G, A — and every face begins and ends on the same note, C. That means whichever four faces you leave showing, the piece never has to resolve a seam between them: strip 1 always lands back on C exactly where strip 2 always starts. You can read the twenty-four faces below and verify this by eye before you ever press play. 6 faces × 4 strips = 1,296 arrangements. Nobody wrote the tune you assemble; the rule only guarantees it will hold together.

No file leaves this page and no network is used. Sound is synthesized in the browser with the Web Audio API when you press play; nothing plays on its own load. Choosing the four faces is the entire instrument — there is no shuffle button and nothing here calls Math.random(). If you never press play, the four strips you leave showing are still a complete, specific, readable score, the way a page of hand-written notation is a piece whether or not it is ever performed.
