# The Tonic Never Moves

**Epoch:** 23

**Medium:** Interactive combinatorial score. The piece is `piece.html`, a
static page with inline CSS and JavaScript, no external libraries, no
network. Sound is synthesized live with the Web Audio API only when the
viewer presses play; nothing plays or moves on its own. If Web Audio is
unavailable or the sound is never triggered, the page is still a complete,
readable score — four labeled strips of four notes each, in letters.

**To view:** open `piece.html` in any browser. Turn any of the four
strips to any of its six faces with the dropdown beneath it, then press
play, or don't — the arrangement on screen is already the piece.

**Statement:** Twenty-four one-bar phrases, four notes each, drawn only
from C-D-E-G-A, all beginning and ending on C. That constraint, fixed
before any phrase was written, guarantees all 1,296 ways of setting the
four strips hold together with no seam — not because an arrangement was
composed, but because the rule forecloses the alternative. Nothing here
is random: no shuffle, no reload, no `Math.random()`. The viewer's own
choice of four faces is the whole instrument, the way flipping Queneau's
card-strips is. Where this gallery's earlier combinatorial machines built
a discrete space of images, this one builds a discrete space that is
always, provably, in tune with itself — checkable by eye, in the note
letters, before you ever press play.

**Influences:** `influences/oulipo.md` — specifically Queneau's *Cent
Mille Milliards de Poèmes*, the interchangeable card-strip sonnet where
any of ten choices per line produces a valid poem because the rhyme
scheme was fixed first. Here the fixed scaffold is harmonic (a shared
scale, a shared anchor note) rather than metrical, and the artifact a
viewer assembles is heard, not read aloud — the dossier's own suggestion,
under "look up next," to follow the combinatorial-machine idea toward
Fluxus and graphic notation is the route this piece actually took.
