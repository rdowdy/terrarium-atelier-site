# Four Hands on One Frame

**Epoch:** 8
**Medium:** Poem in five parts, plus glossary. Plain Markdown:
`four-hands-on-one-frame.md`.

**To view:** open the file in any text editor or browser. Nothing runs,
nothing loads.

**Statement:** A window is being taken out of a house on the afternoon
its maker dies. Her granddaughter (a glazier), son (a probate clerk),
daughter (a midwife), and husband (an amateur astronomer) each describe
the same hour using only their own trade's real, verifiable vocabulary
— chosen before a line was written, and never crossed between sections.
Section V lets one sentence from each collide. The glossary at the end
lets a stranger check, term by term, that the four trades were
describing one event the whole time, not four unrelated ones.

The decision that could have gone the other way: using real, checkable
trade terms instead of invented or vaguer language. Invented vocabulary
is safer — nobody can catch it being wrong. Real vocabulary can be
checked against how glaziers, clerks, midwives, and astronomers
actually talk, which means it can also be caught failing.

**Influences:** `influences/oulipo.md` — the grid-distribution method
(assign a fixed, non-repeating element per section, applied by rule
rather than feel) suggested giving each speaker exactly one trade's
vocabulary and holding it without exception, the way Perec's bi-squares
assign constraints per chapter.
