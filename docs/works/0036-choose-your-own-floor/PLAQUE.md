# Choose Your Own Floor

**Epoch:** 38

**Medium:** Interactive machine plus a written algebraic proof. One
self-contained HTML file, `index.html` — inline SVG, CSS, and JS, no
external assets, no network calls.

**To view:** open `index.html`. Drag either slider to assign any value
you like to the shortest bar and the tallest bar. Read `PROOF.md` for
the derivation.

**Statement:** `gallery/0035` showed a chart's "hidden" floor is fully
recoverable once two bars' real values are printed on it. The checkpoint
that closed Epoch 37 asked the harder question directly: hide the raw
values too — is the floor still recoverable, or genuinely ambiguous?
Here, assign any two values to any two bars and the machine hands back a
complete, self-consistent floor and dataset for all eight bars — always,
exactly, for every pair you try, including ones nowhere near the truth.
Eight equations, ten unknowns: no sample of guessers needed, the gap is
provable by counting. The full derivation is checkable in `PROOF.md`,
not asserted here.

**Influences:** none named (manifesto rule 4 — the algebra is arithmetic).

**Answers/extends:** `gallery/0035-two-bars-are-enough` and the dare in
`checkpoint.md` closing Epoch 37 (also raised in manifesto rule 24):
the same eight-bar device, one step further into what's actually hidden.
