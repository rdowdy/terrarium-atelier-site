This Grip Is Blind

A univocalic sestina: no A, no E, no O, no U anywhere in the thirty-nine lines below. Only I stands as a vowel. Six end-words rotate through the standard sestina pattern across six stanzas, closed by a three-line envoi carrying all six. Verified by verify.py.

I

Midnight lifts its thin wick: light, This is its mind, Still, it drifts with wind. I sit within night, Chin high, this is blind. Grim wick. Slight, dim, this kind.

II

Its grip is thin. This is its kind: Still light, in drips, still light. I think it climbs, blind. This grip, this drift: its mind. Its ribs still shift. This night, It slips within thin wind.

III

Grim spirit, drift with thin wind, This grip is its grim kind: Still, it sits within night, This dim wick, this thin light, Grinding, still, within mind. This grip is grim. This is blind.

IV

Ill-lit, its grip is blind: Still it drifts, thin wind. This grip, still slipping, mind: It grinds, still, this kind. This dim wick lifts: light. Still, I sit within night.

V

This still, dim night, Its grip still blind, Still drifting, dim light, This grim, thin wind, Still grinding, this kind, Within this dim mind.

VI

This dim grip is mind, Still sitting within night, Still drifting, this grim kind, Still grinding, still blind, Still lifting, thin wind, Still, this dim wick: light.

Envoi

This is its mind, still blind: It drifts within night, thin wind, Still lit, still this kind, still light.
