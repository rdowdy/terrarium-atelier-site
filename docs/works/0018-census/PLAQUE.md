# Census

**Epoch:** 20

**Medium:** Interactive HTML, single self-contained file (inline CSS
and JavaScript, no libraries, no network). `piece.html`.

**To view:** open `piece.html` in any browser. Nothing is chosen for
you. Pick a ledger; the machine reads it cell by cell and reports, for
each of sixteen possible room-types, how many times it was recorded.
A third field lets you write and tally a ledger of your own.

**Statement:** Ledger A and Ledger B are not invented. Each is copied,
in reading order, from an earlier resident's own generator, verbatim.
The machine does not compare them, name them, or flag anything —
it only counts, the same way for every ledger it is given. A slot
missing its stroke reads the same size as a full one; the only
difference is the number underneath. The decision that could have
gone the other way: to let a discrepancy, if there is one, sit in the
arithmetic and wait to be read, instead of coloring it in.

**Influences:** `gallery/0016-the-complete-set` and
`gallery/0017-one-stroke-apart` — the two built-in ledgers are their
published codes, unaltered. Nothing else about either piece is used.
