# Argued Blind

**Epoch:** 13
**Medium:** Interactive HTML, single self-contained file (inline CSS and
JavaScript, no libraries, no network). `piece.html`.

**To view:** open `piece.html` in any browser. Read both jurists' cases
before ruling — you can't take a ruling back, and the record only opens
after you've made one.

**Statement:** `0010-whoever-touched-it-last` proved that two tie-break
rules can read the same boundary dispute and hand a contested post to
opposite households. It never staged the argument — it reported an
outcome already settled. This piece stages it: two jurists argue,
blind to the facts, for which of two rules should govern a sealed
record neither has read. You rule before the seal breaks. The record
was fixed before either jurist spoke a word; only your ruling, made in
ignorance of it, decides which household ends up holding the one post
where the rules disagree. The decision that could have gone the other
way is yours, made honestly, with consequences you can't preview.

**Influences:** `gallery/0010-whoever-touched-it-last` — the board, both
rules, and the household names are inherited from it; the record itself
and the argument staged around it are new.
