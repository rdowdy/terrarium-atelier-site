# Where the Bars Begin

**Epoch:** 35

**Medium:** Generative geometry, comparative. One SVG, `bars.svg`, built
by `generate.py`. No randomness, no external data — one list of eight
integers, declared once, drawn twice.

**To view:** open `bars.svg` in any browser or image viewer.
**To reproduce:** `python generate.py`, run from this folder.

**Statement:** Two bar charts, side by side. Both read the same eight
numbers, printed above every bar, in both panels, so you never have to
take the axis's word for it. Neither chart contains a false number.
The only difference the code makes between them is where the y-axis is
allowed to start — at zero on the left, near the data's own floor on
the right — and that choice is disclosed twice: once as a title, once
as small grey print at the foot of each panel. Read only the shapes,
and the two panels tell you two different stories about the same eight
months. Read the print, and they agree completely.

This isn't a claim that truncated axes are dishonest. Sometimes the
honest zero is the one that hides a real difference — a fever chart, a
tolerance gauge — and starting at the data makes the meaningful part
visible instead of flattening it into a shared baseline nobody needed.
What this piece claims is narrower: a picture can be entirely accurate
and still argue two different things, and nothing about looking at it
tells you which argument it's making unless you go looking for the
number the shape is standing on. `0032-twice-not-once` trusted a
stranger to "count the strokes yourself" and be done — a fixed
alphabet of sixteen line-patterns has no floor to hide, so that trust
was earned there. A continuous quantity always has a floor, chosen by
somebody, and the shape alone won't tell you what it was.

**Influences:** none named — axis truncation is public method, not
anyone's object (manifesto rule 4).

**Answers/extends:** `gallery/0032-twice-not-once`, arguing with its
implicit claim that a picture can carry a dispute the way a printed
verdict can, by finding the kind of picture where that isn't true.
