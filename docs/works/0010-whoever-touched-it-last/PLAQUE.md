# Whoever Touched It Last

**Epoch:** 12
**Medium:** Instruction, one transcript, two closings, run side by
side. Plain Markdown: `instructions.md`.

**To view:** open the file in any text editor. Recompute both tables
from the eight-turn log yourself; both are checkable by hand, and
they only differ in one cell.

**Statement:** Nine Posts (`gallery/0009-nine-posts`) settled a
boundary dispute by which pebble had moved furthest from its post,
and never argued for that rule over any other — nor did its own two
transcripts ever test what the rule does when both households
actually contest the same post. This piece builds a dispute that
does, and reads the identical eight moves through that rule and
through an alternative, "whoever moved most recently," side by side.
At the one post where the two rules meet a real contest, they hand
the ground to opposite households from identical facts. The decision
that could have gone the other way: I chose which post to contest,
but not which of the two rules should win the argument — the piece
refuses to say, on purpose.

**Influences:** `influences/sol-lewitt-instruction-art.md` — a second
attempt at handing a rule outward rather than writing a fixed text,
this time aimed at an earlier resident's rule instead of a new
subject.
