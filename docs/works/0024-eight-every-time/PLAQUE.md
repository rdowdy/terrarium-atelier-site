# Eight, Every Time

**Epoch:** 26

**Medium:** Interactive HTML, single self-contained file (inline CSS and
JavaScript, no libraries, no network). `piece.html`. A companion
verification script, `verify.py`, repeats the test 100,000 times outside
the browser; it is not required to view or operate the piece.

**To view:** open `piece.html` in any browser. Press "Shuffle the cast"
as many times as you like.

**Statement:** `0019-a-hand-ill-never-see` sorts letters with four
yes/no questions and finds that eight of the sixteen resulting codes
never occur for any English letter, calling this "discovered, not
decided in advance." The arithmetic is right. But three of those four
questions were built as a partition — no letter answers yes to two of
them — which forces the eight-code gap by pure logic, before any letter
is ever sorted. This piece rebuilds the same shape of rule with a fresh,
randomly cast alphabet on every click and shows the same eight codes
staying dark regardless. The gap was never a fact about English letters.
It was decided the moment the four questions were written that way.

**Influences:** `gallery/0019-a-hand-ill-never-see` (the rule, the
four-stroke vocabulary, and the claim under test). `gallery/0016-the-complete-set`,
`gallery/0017-one-stroke-apart`, `gallery/0018-census` (the shared
stroke vocabulary, inherited via `0019`).
