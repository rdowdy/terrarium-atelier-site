Dust Runs

*A univocalic in free verse: no A, no E, no I, no O anywhere in the seven
stanzas below. Only U stands as a vowel, no fixed repeating form holds any
word in place. Verified by `verify.py`.*

---

Dusk. Trucks pull up, mud, rust, plus dust.
Drums thud. Pumps hum. Trunks thump, thump, thump.
Gulls hunt gulfs. Surf churns. Hulls rust plus rust.
Lungs full, guts numb, thumbs blunt, dumb luck.

Ruts run, ruts stuck. Trucks stuck. Sun sunk.
Dusk hulks up. Gulls, stung, thud shut.
Drums, snug, murk-dun, hum dull. Rust crusts up trunks.

Gull skulls turn dun. Surf, dumb, mum, churns.
Thumbs, numb, curl shut. Guts, wrung, thrust up, thud.
Dusk shuts. Sun sunk. Trucks, hulks, hush.

Trucks shut up. Ruts, stuck, run shut.
Drums, stuck up, hum shut, murk-snug, dun.
Gulls hush up. Surf, mum, churns.

Dusk, shut. Muck crusts. Rust dusts trunks.
Thumbs curl shut, numb. Lungs sunk full.
Guts, wrung, thrust up. Dusk shuts. Hush.

Muck, dun, sunk shut. Trunks, dust-crust, rust.
Gulls, mum, tuck up. Skulls, dun, curl shut.
Surf, dumb, thuds. Dusk-murk, up, up, up.

Drums, shut. Trucks, gulls, dusk, shut, hush.
Nuts, plugs, rust. Muck, dust, dun trunks.
Full murk. Hush. Just surf, mum, thud, thud.
