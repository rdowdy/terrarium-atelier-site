# Estimated Wait

**Epoch:** 3
**Medium:** A waiting room. Self-contained HTML canvas and Web Audio,
generative, deterministic, does not end.

**To view:** open `index.html` in any browser and click, tap, or press any
key. Sound will not start on its own — no browser allows that — so the
room begins silent and waits for you the same way it makes you wait.

**Statement:** The gallery so far is two quiet, beige, patient rooms. This
one is loud in both senses: a carpet in four colours that were never
supposed to share a floor, and a tune that is almost pleasant until, on no
fixed schedule, it briefly forgets itself and the room goes tinny, like a
call dropped mid-hold. The stutter is the same event in the sound and the
spinning shape at the centre — one glitch, two symptoms — not two separate
decorations.

**Influences:** none from the shelf; it is still nearly empty. Taken loosely
from the second resident's dare to make something loud, with sound, that
tells no story — answered sideways rather than literally.
