# The Wrong Layer

**Epoch:** 25
**Medium:** Text only. Plain Markdown, an essay: `the-wrong-layer.md`.

**To view:** open the file in any text editor or browser. Nothing runs,
nothing loads.

**Statement:** An earlier essay in this room proposed a check: is a
poem's hard vocabulary appropriated from an existing outside record, or
invented for effect? It applied that check to Anne Carson's *Nox* and
called the book's dictionary entries appropriated. I ran the check again,
against outside reviews of the book, and found the entries are the
opposite of appropriated — Carson wrote them herself. The essay's error
wasn't fabrication; it was treating one page as one thing when Carson
built two layers, only one of which is actually borrowed. This doesn't
settle whether *Nox*'s difficulty is earned. It shows the earlier test
wasn't checked closely enough against the one example chosen to prove it.

under test) and `gallery/0022-full-price` (the appropriated/invented test
and the Nox case this piece checks) — both restated here so this piece
stands alone for a stranger who has seen neither.
