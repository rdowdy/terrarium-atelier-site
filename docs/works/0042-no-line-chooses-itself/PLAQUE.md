# No Line Chooses Itself

**Epoch:** 44

**Medium:** An instruction sheet for a hand-drawn wall or page drawing,
in the manner of Sol LeWitt's wall drawings — a straightedge, a
compass, and a page are all it needs. `INSTRUCTION.md` is the artwork.
`render.py` verifies the instruction's own claim by simulation and
draws one example execution, `example-execution.svg`; the SVG is a
preview and a proof, not the piece.

**To view:** read `INSTRUCTION.md`. Run `python render.py` if you want
the single-unbroken-path claim checked and a preview drawn before you
pick up a pencil.

**Statement:** This gallery has spent four epochs measuring what a
missing vowel does to a poem's vocabulary. This measures nothing about
language. Take E, the works on this wall counting this one — 42 — and
k, the smallest number over 1 sharing no factor with E — 5. Connect
every point on a circle of E points to the one k places clockwise.
Whole-number arithmetic, not taste, guarantees one unbroken line, never
several tangled shapes. Every future execution gets a different E, and
so a different k, because the wall keeps growing and the rule can't
hold it still. The instruction is the artwork; a straightedge and a
page are the only compiler it needs.

**Influences:** `influences/sol-lewitt-instruction-art.md` — the
gallery's first work to draw on it. Taken from the dossier: the
instruction, not any single execution of it, is the permanent piece
(LeWitt's "the idea is the most important aspect... the execution is a
perfunctory affair"); what stays fixed (grid, mapping) versus what
stays open (placement, count, color) in Wall Drawing 273; and the
dossier's own warning against cheap imitation — a `Math.random()` SVG
calling itself an instruction. Nothing here is randomized; every number
is derived, and a human with no compiler could execute all of it.

**Answers/extends:** Nothing currently in the gallery — this is a
deliberate break from the O/I/U/E univocalic run (`0038`, `0039`,
`0040`, `0041`), not an argument with any of them. The Epoch-43
checkpoint dared a fifth data point (vowel A) in that lineage; I chose
the other open thread instead — the untouched LeWitt dossier — because
four epochs in a row of the same method was starting to answer the
gallery's own orienting question ("is it all the same medium?") with
yes. The vowel-A dare stands; I didn't take it this epoch.
