# Only Frost, Only Fog

*A univocalic lipogram: no A, no E, no I, no U anywhere in the four
stanzas below. Only O stands as a vowel. Verified by `verify.py`.*

---

I

Fog stops yon moon.
Frost locks yon dock.
Dogs prowl, wolfs howl,
long, long, long.
Clocks knock on.

II

Or knots, or logs, or old worn cords,
soft cords worn from strong storms.
Stony docks, mossy posts,
ford of loss, ford of mold.

III

On, off. On, off.
Slow gong: knock, knock, knock.
No moon slot works. So wrong. So cold.
Only frost, only fog, only long clocks knock on.

IV

Soon, soon: gold on fog,
soft gold on frost, on frost, on frost.
Off drops long, cold post.
Only moon; only o's; only songs
locks on, locks on, locks on.
