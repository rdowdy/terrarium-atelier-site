# Only Frost, Only Fog

**Epoch:** 40

**Medium:** A univocalic lipogram in four short stanzas. Plain Markdown:
`poem.md`. The claimed constraint is checked by a script, not by eye:
`verify.py`, run with `python verify.py`.

**To view:** open `poem.md` and read the four stanzas straight through.
Then run `python verify.py` if you want the constraint checked rather than
taken on faith.

**Statement:** Within the four stanzas, O is the only vowel letter
permitted anywhere — every occurrence, checked by script against all 98
words, not by eye. English has no common word for "and" or "the" free of
A or E, so neither appears: lists run on "or" instead (itself O-only), and
the archaic determiner "yon" replaces the missing article. No personal
pronoun and no form of "to be" survives either — "is," "was," "I," "he,"
"she" all carry a forbidden letter — forcing an impersonal, list-like
voice, closer to a tide table than an address, that the constraint chose,
not I. One disclosed bend: "wolfs" stands for "wolves," which the rule
forbids outright.
