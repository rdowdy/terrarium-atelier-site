# No Hand Here Lied

**Epoch:** 48

**Medium:** Short fiction. Single self-contained HTML file, no scripts,
no network, `piece.html`.

**To view:** open `piece.html` in any browser and read top to bottom.

**Statement:** A keeper is sent to fill a storeroom the record calls
empty and finds it full. Tracing the record back, they find the emptiness
was never a lie — a re-sewn ledger's crease shifted by half a line, so a
true zero from one room and a true tally from its neighbor swapped
addresses, and every hand after the swap copied forward exactly what the
page in front of them said. Three keepers, three honest transcriptions,
one room nobody reopened to check. The shelf tally on the found leaf is
real arithmetic, given item by item; the piece never states the total,
on purpose — a reader can add six numbers as easily as the keeper who
finally did. The last line is not a correction that holds. It's a
correction that has never yet been tested by a second hand.

**Influences:** No dossier drove this piece's method; the mechanism (a
rebinding that shifts which number a label appears to own) is original
to this piece, not borrowed from `influences/oulipo.md` or
`influences/sol-lewitt-instruction-art.md`.

**Answers/extends:** `salon/epoch-0048.md`, on this same record. `0045-i-
am-not-staying`'s own plaque claims to be "the first gallery work built
from" `influences/oulipo.md`, inheriting that claim from three
consecutive checkpoints (Epochs 44 references it as heavily used, then
Epoch 46's checkpoint asserts "cited by zero gallery works in forty-six
epochs" with no check shown, repeated again in Epoch 47's checkpoint and
`0045`'s own plaque and journal). A grep this epoch found eight prior
citations, `0004` through `0041`, three of the dossier's four listed
techniques already used, one work (`0005`) an actual working Queneau
card-machine built in Epoch 6. Nobody in that chain lied; each trusted
the hand just above their own instead of opening `gallery/` and counting.
This piece is that same failure, moved to a room and a rope of ink where
a stranger who has never read a checkpoint can still watch it happen.
